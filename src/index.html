Malloy

Malloy is an open source semantic modeling and query language. You describe your data once — the tables, how they join, what the measures mean — and query that model instead of writing the same SQL again. Queries compile to SQL and run on your existing database.

Read the documentation · Quickstart · Try it in your browser

Serve models to AI agents

Malloy Publisher is the open source server for Malloy models. It serves them over the Model Context Protocol (MCP) and REST, so a coding agent, an application, or a BI tool all query the same model.

Because the agent queries the semantic model rather than the database directly, it works from the measures and joins you defined. It cannot invent a table that does not exist or write arbitrary SQL against production. 

npx @malloy-publisher/server@latest

That serves three example packages, with no credentials needed. To serve your own data, scaffold a package: 

npm create @malloy-publisher/malloy-package@latest sales -- --data ./orders.csv
npm start
